# Distributed Notification System

A distributed notification backend separating API responsibilities from email and push workers.

## Features

- Notification API
- domain, infrastructure and shared components
- independent email and push workers
- container orchestration configuration

## Technology stack

C#, .NET, Docker Compose.

## Getting started

Review `NotificationSystem.sln`, the projects under `src/`, and `docker-compose.yml`. Configure fresh development credentials and local dependencies before running Docker Compose. Never reuse or publish credentials stored in example configurations.
